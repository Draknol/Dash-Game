## Setup
1. Install cmake
2. Clone the repository: `git clone https://github.com/Draknol/Dash-Game`
3. Configure CMake `cmake -B build`
3. Build `cmake --build build`
3. Run `.\build\DashGame.exe`

## Features
* Editable .map files
* Animation support
* Custom made collision and physics
* Level swapping
